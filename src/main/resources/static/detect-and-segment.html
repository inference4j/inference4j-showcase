Detect & Segment

D-FINE finds the objects, SAM 2.1 outlines each one. Every box becomes an exact mask and a cut-out.

The detector returns rectangles. SAM's encoder runs once on the image, then each rectangle is passed to its prompt decoder as a box prompt, giving one mask per object. 

ImageFeatures features = sam.encode(image);
for (Detection d : detector.detect(image)) {
    SegmentationMask mask = sam.segment(features, Prompt.box(d.box()));
    BufferedImage cutout = mask.applyTo(image);
}
