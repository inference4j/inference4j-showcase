Click to Segment

Click any object and SAM 2.1 outlines it. The image is encoded once, so every click after that is fast.

Drop an image here or

Include: click the object. Exclude: click a part the mask should not cover. Box: drag a rectangle around the object.

On upload the server runs SAM 2.1's image encoder once and keeps the result (ImageFeatures). Each click or box then runs only the small prompt decoder, which proposes three masks with a predicted quality score. 

ImageFeatures features = sam.encode(image);          // once per image
List<SegmentationMask> masks = sam.segmentCandidates(features,
        Prompt.point(320, 240).withBackground(300, 400));
BufferedImage cutout = masks.get(0).applyTo(image);
